# Дюшес · Ковдри

Односторінковий сайт швейної студії **Дюшес** (Instagram [@dushes.com.ua](https://www.instagram.com/dushes.com.ua/)):
чотири кольори стьобаних ковдр, акція «безкоштовна доставка до Нового року», замовлення з Новою Поштою / Укрпоштою
та онлайн-оплата MonoPay або LiqPay.

## Що де лежить

| Шлях | Що це |
|---|---|
| `index.html` | Увесь сайт. Ціна, акція, характеристики, контакти — у блоці `CONFIG` унизу файлу |
| `img/` | Логотип, головне фото, фото ковдр (`*-1.jpg` без чохла, `*-2.jpg` у чохлі), фото догляду, грушки |
| `cloudflare-worker/worker.js` | Сервер оплати MonoPay / LiqPay, підказки Нової Пошти, заявки й замовлення в Telegram |
| `ІНСТРУКЦІЯ.md` | Покроковий запуск: GitHub Pages + Cloudflare + Telegram |

## Сторінки

- головна — перший екран, «Чому Дюшес», ковдри, наповнення, акція, догляд, відгуки, замовлення, питання;
- `#pro-nas` — «Про нас»;
- `#spivpratsia` — «Співпраця».

## Важливо

Ключі MonoPay, LiqPay, Нової Пошти й Telegram **ніколи не додавайте в цей репозиторій** —
тільки в налаштування Cloudflare Worker (див. `ІНСТРУКЦІЯ.md`, крок 3).

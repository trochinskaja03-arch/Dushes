# Сайт Дюшес · Ковдри — запуск на GitHub Pages + Cloudflare

Усе безкоштовно. Сайт лежить на GitHub Pages, а оплата й Нова Пошта працюють
через маленький сервер на Cloudflare Workers (безкоштовно до 100 000 запитів на день).
Замовлення приходять вам у Telegram.

```
index.html          ← сайт (GitHub Pages показує його з кореня репозиторію)
img/                ← логотип, фото ковдр, догляду, грушки
.nojekyll
cloudflare-worker/
  worker.js         ← це вставляєте в Cloudflare
ІНСТРУКЦІЯ.md
```

Робіть кроки по черзі: адреси з кроків 1–3 потрібні в наступних.

---

## Крок 1. Telegram-бот для замовлень (5 хвилин)

1. У Telegram відкрийте **@BotFather** → `/newbot` → придумайте назву.
   Він видасть **токен** виду `123456:ABC...` — збережіть.
2. Напишіть своєму новому боту будь-яке повідомлення (наприклад «привіт»).
3. Відкрийте **@userinfobot** → він покаже ваш **Id** (число) — це `TELEGRAM_CHAT_ID`.
   Якщо замовлення мають приходити в групу: додайте бота в групу, а chat id групи візьміть через @RawDataBot (число з мінусом).

## Крок 2. Сайт на GitHub Pages

1. github.com → **New repository** → назва, напр. `dushes` → **Public** → Create.
2. **Add file → Upload files** → перетягніть **увесь вміст** розпакованої папки `dushes` (index.html, папки img і cloudflare-worker, ІНСТРУКЦІЯ.md, README.md і файл .nojekyll) → **Commit changes**.
   Файл `.nojekyll` прихований: якщо не видно, увімкніть показ прихованих файлів або створіть його в репозиторії: Add file → Create new file → назва `.nojekyll` → порожній → Commit.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 хвилини там з'явиться адреса сайту, напр. `https://imya.github.io/dushes/` — це ваш **SITE_URL**.

## Крок 3. Сервер оплати на Cloudflare

1. Зареєструйтесь на **dash.cloudflare.com** (картка не потрібна).
2. **Workers & Pages → Create → Create Worker** → назва `dushes-pay` → **Deploy**.
3. **Edit code** → видаліть усе в редакторі → вставте весь вміст `cloudflare-worker/worker.js` → **Deploy**.
4. Скопіюйте адресу воркера, напр. `https://dushes-pay.imya.workers.dev`.
   Відкрийте її в браузері: має показати `{"ok":true,"service":"dushes-pay"}`.
5. **Settings → Variables and Secrets → Add**. Додайте (тип *Secret* для ключів):

| Назва | Значення |
|---|---|
| `SITE_URL` | адреса з кроку 2, без `/` в кінці: `https://imya.github.io/dushes` |
| `TELEGRAM_BOT_TOKEN` | токен з кроку 1 |
| `TELEGRAM_CHAT_ID` | id з кроку 1 |
| `MONO_TOKEN` | web.monobank.ua → еквайринг → токен API (для тесту — тестовий токен з api.monobank.ua) |
| `LIQPAY_PUBLIC_KEY` | liqpay.ua → магазин → API → публічний ключ |
| `LIQPAY_PRIVATE_KEY` | там само → приватний ключ |
| `LIQPAY_SANDBOX` | `1` поки тестуєте; видаліть перед запуском |
| `NP_API_KEY` | business.novaposhta.ua → Налаштування → Безпека → API-ключ |

   Після додавання натисніть **Deploy**, якщо Cloudflare попросить.

> Ключі вписуються **тільки в Cloudflare**. У файли на GitHub їх не можна додавати ніколи:
> репозиторій публічний, і будь-хто їх побачить.

## Крок 4. З'єднати сайт із сервером

На GitHub відкрийте `index.html` → олівець **Edit** → знайдіть рядок

```js
apiBase: 'https://dushes-pay.YOUR-NAME.workers.dev'
```

і впишіть адресу воркера з кроку 3 → **Commit changes**. Через хвилину сайт оновиться.

## Крок 5. Перевірка

1. Відкрийте сайт, додайте ковдру, почніть вводити місто — мають з'явитися підказки Нової Пошти.
2. Оформіть замовлення з LiqPay (з `LIQPAY_SANDBOX=1` гроші не списуються).
   У Telegram прийде «🛒 Нове замовлення», після оплати — «✅ Оплачено LiqPay».
3. monopay: перевірте з тестовим токеном, потім замініть на бойовий.
4. Перед запуском: видаліть `LIQPAY_SANDBOX`, поставте бойовий `MONO_TOKEN`.

У кабінеті LiqPay у налаштуваннях магазину вкажіть адресу сайту.

## Що замінити перед запуском

Ціну й знижки треба міняти **у двох місцях**: на сайті (що бачить клієнт) і в сервері (скільки списується).

| Що | Сайт: `index.html`, блок `CONFIG` | Сервер: `worker.js` |
|---|---|---|
| Ціна (зараз 2 699 ₴) | `price` | `DEFAULT_PRICE` (або змінна `PRICE_UAH`) |
| Знижки (зараз немає) | `discounts` | `DISCOUNTS` |
| Дата кінця акції «безкоштовна доставка» (31.12.2026) | `promoUntil` | `PROMO_UNTIL` |

Після дати кінця акції блок із відліком сам зникне з сайту, а доставка в кошику стане «за тарифами перевізника».
Заявки «Нагадайте мені» з блоку акції приходять у Telegram з позначкою 🎁 — нагадайте цим людям до 28 грудня.

Тільки в `index.html`:
- `freeShipFrom` — поріг безкоштовної доставки після акції (зараз `0` — вимкнено);
- `size`, `spec` — розмір і характеристики;
- `contacts` — телефон, пошта;
- блок «ВІДГУКИ» — справжні відгуки замість прикладів;
- фото: покладіть файли в `img/` на GitHub (Add file → Upload files) і впишіть назви:
  - ковдри: `photo: 'img/fioletova.jpg'` у `COLORS` для кожного кольору;
  - перший екран: `hero: { photo: 'img/stos.jpg', video: 'img/hero.mp4' }`;
  - «Про ковдру»: `about: { photo: '…', video: '…' }`.
  Відео — mp4 до ~8 МБ, без звуку.
